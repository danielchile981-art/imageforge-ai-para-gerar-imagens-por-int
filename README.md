# ImageForge AI para gerar imagens por int

Crie um aplicativo chamado ImageForge AI para gerar imagens por inteligência artificial a partir de prompts em português. Quero também escolher uma imagem da galeria e editar por texto, por exemplo trocar fundo, remover objetos, mudar cores e transformar o estilo. Adicione opções quadrado, retrato e paisagem, qualidade rápida, média e alta, botão para baixar, compartilhar e histórico das imagens

Gerado pelo AppForge Local 2.0. Tipo: image-ai.
